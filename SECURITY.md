# Security policy

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Report it privately through [GitHub Security Advisories](https://github.com/nexara-global/paprel-embed-ui-examples/security/advisories/new).

Include the affected revision, reproduction steps, impact, and any suggested mitigation. We will acknowledge valid reports as quickly as practical and coordinate disclosure after a fix is available.

Never include App Connect client secrets, access tokens, customer data, or production credentials in a report.

## Supported versions

Before the first stable release, security fixes are provided on the latest revision only. This policy will be revised if versioned releases or long-term support branches are introduced.
